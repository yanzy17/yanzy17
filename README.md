# MASTER PROMPT AI

E-book HTML/CSS premium siap dijadikan PDF.

## Isi File

- `index.html` — seluruh isi e-book **MASTER PROMPT AI**.
- `style.css` — styling premium, responsive, dan print-friendly.
- `README.md` — panduan membuka dan export PDF.

## Cara Membuka

1. Buka file `index.html` di browser.
2. Pastikan file `style.css` berada di folder yang sama.
3. Scroll untuk membaca e-book atau gunakan daftar isi di halaman awal.

## Cara Export ke PDF

1. Buka `index.html` di browser.
2. Tekan `Ctrl + P` atau `Cmd + P` di Mac.
3. Pilih **Save as PDF**.
4. Aktifkan **Background graphics** agar gradient, card, dan warna cover ikut tersimpan.
5. Simpan file PDF.

## Catatan Print

CSS sudah memiliki aturan `@media print`, termasuk page break, warna yang dipertahankan, dan layout yang lebih ramah PDF. Jika hasil PDF terlalu besar, gunakan pilihan skala 90–95% di dialog print browser.
