# BAGIAN 15 — CARA MENYUSUN ZIP SIAP JUAL

## Langkah 1 — Buat folder
Di laptop/HP, buat 1 folder induk: **`MULAI DARI NOL - Starter Kit`**.
Di dalamnya, buat folder sesuai struktur (01 sampai 08) + 1 file "BACA INI DULU".

> Di HP: pakai app file manager / Google Drive (bisa bikin folder langsung di Drive).

## Langkah 2 — Cara menamai file
- Pakai nama jelas + rapi: `Mulai-Dari-Nol-Panduan-Utama.pdf`.
- Awali folder dengan nomor (01, 02, ...) biar urutannya kebaca rapi.
- Hindari spasi aneh, simbol, atau nama "Final2_fix_REVISI".
- Konsisten: semua Title Case atau semua-pakai-strip.

## Langkah 3 — Cara menyusun isi ZIP
Masukin tiap file ke folder yang sesuai (lihat struktur final di bawah). Pastikan:
- File "BACA INI DULU" ada paling depan (di luar folder bernomor).
- Tiap folder gak kosong.
- Gak ada file draft/mentah yang keikut.

## Langkah 4 — Export PDF dari Canva / Google Docs
- **Canva:** Share → Download → pilih **PDF Standard** (cukup untuk dibaca). Pakai PDF Print kalau mau cetak.
- **Google Docs:** File → Download → **PDF Document (.pdf)**.
- Cek ulang: halaman gak kepotong, link aktif, font kebaca.

## Langkah 5 — Upload ke Google Drive
1. Kompres folder induk jadi `.zip` (klik kanan → Compress / pakai app zip di HP).
2. Upload ZIP ke Google Drive.
3. Klik kanan → Share → ubah ke **"Anyone with the link" (Viewer)**.
4. Simpan linknya.

## Langkah 6 — Upload ke Lynk ID / Gumroad
**Lynk ID:**
1. Buat akun → tambah produk → tipe **Produk Digital**.
2. Upload file ZIP langsung, atau tempel link Google Drive.
3. Isi judul, deskripsi (pakai folder 05 → Template Halaman Jualan), harga, cover.
4. Publish.

**Gumroad:** alurnya mirip — New Product → Digital → upload file → set harga → publish.

## Langkah 7 — Cara membuat deskripsi produk
Pakai **Template Halaman Jualan** (folder 05) & **Template Deskripsi Produk**. Mulai dari masalah pembeli, lalu solusi, isi paket, bonus, FAQ, CTA.

## Langkah 8 — Cara memberi akses pembeli
- **Lynk ID/Gumroad:** otomatis. Pembeli bayar → langsung dapat tombol download.
- **Manual (Drive):** kirim link Drive setelah pembayaran masuk. Aktifkan akses "Anyone with the link".
- Tips: kalau manual, balas cepat biar pembeli gak nunggu lama.

## Langkah 9 — Checklist sebelum produk dijual
☐ Semua file udah jadi PDF & kebaca rapi
☐ Gak ada typo di cover & 3 halaman pertama
☐ Struktur folder rapi & bernomor
☐ File "BACA INI DULU" ada
☐ ZIP udah dites buka (gak corrupt)
☐ Link Drive udah dites dari akun lain (akses jalan)
☐ Cover & thumbnail udah dipasang
☐ Deskripsi & harga udah diisi
☐ Coba "beli" sendiri buat tes alur akses
